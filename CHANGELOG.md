# Changelog

Все значимые изменения в проекте pySDA будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [3.1.4] - 11-10-2025 - Hotfix: Двойная проверка сессии и улучшенная валидация cookies

### Added
- 🔍 **Двойная проверка сессии**: Добавлен новый метод `check_session_via_trade_url()` для дополнительной проверки активности сессии через trade URL
- 🔄 **Комплексная валидация**: Сессия теперь проверяется через два разных endpoint'а для повышения надежности
- 📝 **Детальное логирование проверок**: Расширенное логирование процесса проверки сессии с указанием результатов каждого метода

### Changed
- 🔧 **Улучшенная логика обновления cookies**: В `CookieManager.update_cookies()` теперь используется двойная проверка сессии перед обновлением
- 🕐 **Оптимизация проверки активности**: Cookies обновляются только если обе проверки (community page + trade URL) показывают неактивную сессию
- 📊 **Информативные логи**: Добавлено логирование результатов каждой проверки для лучшей отладки

### Fixed
- 🐛 **Ложные срабатывания обновления cookies**: Исправлена ситуация когда cookies обновлялись при активной сессии из-за неточной проверки
- 🔄 **Логическая ошибка валидации**: Теперь время последнего обновления корректно обновляется при активной сессии
- ⚡ **Избыточные обновления**: Предотвращение ненужных обновлений cookies когда сессия фактически активна

### Technical Details
- 🔍 **Метод check_session_via_trade_url()**: Проверяет сессию через trade offer URL с анализом редиректов на login
- 🔄 **Двойная валидация в update_cookies()**: `is_username_exist_via_trade_url && is_username_exist` для подтверждения активности
- 📝 **Расширенное логирование**: Детальные логи каждого этапа проверки сессии для диагностики
- 🎯 **Улучшенная надежность**: Снижение ложных срабатываний благодаря комплексной проверке

## [3.1.3] - 17-08-2025 - Унификация времени жизни cookies

### Added
- 🔧 **Глобальная настройка max_cookie_age_minutes**: Добавлена настройка в config.yaml для централизованного управления временем жизни cookies
- 📋 **Метод get_max_cookie_age_minutes()**: Новый метод в ConfigManager для получения настройки времени жизни cookies
- 🌐 **Глобальный экземпляр конфига**: Добавлен global_config для использования настроек во всех модулях

### Changed
- 🕐 **Единое время проверки cookies**: Все компоненты (CookieChecker, CookieManager, декораторы) теперь используют одинаковое значение из конфига
- 🔄 **Динамическое получение настроек**: Время жизни cookies читается из конфига при каждом обращении, что позволяет изменять настройки без перезапуска
- 📝 **Улучшенное логирование**: Сообщения в логах теперь показывают актуальное время из конфигурации вместо хардкода
- 🏗️ **Упрощенная архитектура**: Убраны лишние параметры config_manager из конструкторов, используется прямой импорт global_config

### Fixed
- 🐛 **Парадокс в логах cookies**: Исправлена ситуация когда CookieChecker и CookieManager использовали разные критерии актуальности cookies
- 🔧 **Логическая ошибка обновления**: Теперь нет ситуации "cookies устарели → успешно обновлены" без показа процесса обновления
- 📊 **Консистентность настроек**: Все места проверки cookies используют одинаковое значение max_cookie_age_minutes из конфига

### Technical Details
- ⚡ **Оптимизация logger_setup.py**: Модуль логирования теперь отвечает только за логирование, убрана загрузка настроек cookies
- 🔄 **Рефакторинг параметров**: Убраны лишние передачи config_manager через конструкторы, используется глобальный импорт
- 🎯 **Единый источник истины**: Все компоненты получают настройки из одного места - global_config.get_max_cookie_age_minutes()

## [3.1.2] - 15-08-2025 - Проверка IP и улучшенное отображение аккаунтов

### Added
- 🔍 **Проверка IP перед каждым Steam запросом**: Новая настройка `check_ip_on_every_steam_request` в config.yaml для отладки работы прокси

### Changed
- 🌐 **Автоматическая проверка IP**: При включенной настройке IP проверяется автоматически перед каждым HTTP запросом к Steam через переопределение методов сессии
- 📝 **Улучшенная читаемость меню**: Все списки аккаунтов теперь показывают описания для лучшей идентификации
- 🎯 **Заголовки меню**: Заголовки главного меню и меню действий теперь отображают полные имена аккаунтов с описаниями
- 🔄 **Упрощенная архитектура**: IP проверка читается прямо из конфига в SteamClient, убрана передача параметра через всю цепочку
- 🏪 **Расширенная отладка market подтверждений**: Добавлено детальное логирование процесса обработки подтверждений маркета

### Fixed
- ⏱️ **Увеличены таймауты cookies**: Увеличен срок действия cookies с 120 до 1200 минут для стабильности
- 🔄 **Оптимизация входа в систему**: Изменен вызов с `update_session()` на `login_if_need_to()` для лучшей производительности
- 🍪 **Улучшенная валидация cookies**: Расширено время жизни cookies и добавлено информативное логирование

### Technical Details
- 🔧 **Переопределение методов сессии**: IP проверка реализована через monkey patching методов `session.get()` и `session.post()`
- 📊 **Динамическое чтение конфигурации**: Настройка IP проверки читается из config.yaml при каждом создании SteamClient
- 🎨 **Улучшенный UX**: Визуальные индикаторы статуса (✅/❌) перенесены в начало строки для лучшего восприятия
