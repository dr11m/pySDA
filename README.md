# 🤖 pySDA - CLI Steam Bot

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![Status](https://img.shields.io/badge/status-active-green.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-4.1.0-green.svg)

> **pySDA - CLI бот для автоматизации Steam подтверждений. Автоматически принимает бесплатные трейды и подарки, подтверждает операции через Steam Guard (весь функционал классического SDA и больше), обрабатывает market ордера, управляет сессиями с автообновлением cookies, запускает изолированные браузерные профили с автозаливкой cookies, выбором прокси и расширений.**

## ✨ Основные возможности (кратко)

**Основные функции:**
- **🎁 Автоматическое принятие подарков** - автоматическое принятие бесплатных трейдов (подарков)
- **🔑 Steam Guard подтверждения** - автоматическое подтверждение операций через мобильное приложение
- **🏪 Управление торговой площадкой** - подтверждение покупок и продаж на steam market
- **🔐 Смена пароля** - безопасная смена пароля через официальный API Steam
- **🌐 Прокси и сеть** - поддержка прокси для каждого аккаунта и диагностика сети
- **🍪 Управление сессиями** - автоматическое обновление cookies и refresh токенов
- **⚙️ Настройки Steam** - управление API ключами и настройками аккаунта

## ✨ Основные возможности (полный функционал)

### 👤 **Действия с аккаунтом**

- **👤 Выбрать аккаунт**: инициализация и загрузка конфигурации выбранного аккаунта
- **🍪 Обновить cookies**: принудительное обновление Steam сессии и получение новых cookies
- **📋 Управление трейдами (получить + управлять)**:
  - **🎁 Принять все подарки**: автоматическое принятие входящих трейдов где вы ничего не отдаете
  - **🔑 Подтвердить все через Guard (входящие + исходящие)**: подтверждение всех трейдов требующих Steam Guard
  - **✅ Принять конкретный трейд**: выбор конкретного трейда из списка для принятия
  - **🔑 Подтвердить конкретный трейд через Guard**: подтверждение выбранного трейда через Steam Guard
- **🏪 Подтвердить лоты на ТП**: подтверждение всех ожидающих операций на торговой площадке Steam
- **🔑 Получить Guard код**: генерация 5-значного кода Steam Guard для ручного использования
- **⚙️ Изменение настроек Steam**:
  - **🔑 Получить/обновить API ключ**: автоматическое создание и проверка Steam API ключа
  - **🔐 Получить список подтверждений Guard**: просмотр и подтверждение всех ожидающих Guard подтверждений
  - **🔒 Смена пароля**: безопасная смена пароля Steam аккаунта через официальный API с подтверждением через Steam Guard


### 🤖 **Автоматизация**
- 🎁 **Автоматическое принятие подарков**: принятие в веб-интерфейсе когда вам дают предметы бесплатно
- 📋 **Автоматическое подверждение guard**: подтверждает основные типы guard операций (покупка/продажа на steam market, подтверждение трейдов, которые вы уже приняли через браузер)
- 🔄 **Непрерывная работа**: автоматическая обработка трейдов с настраиваемыми параметрами
- ⏰ **Настраиваемые интервалы**: гибкая настройка времени проверки и обработки
- 🛡️ **Безопасность**: контроль над тем, какие трейды принимаются автоматически
- 🌐 **Прокси для каждого аккаунта**: возможность указать индивидуальный HTTP/SOCKS прокси для каждого аккаунта в конфиге
- 📦 **Сохранение cookies в формате JSON или в базе данных**: выбор способа хранения cookies через конфиг с автоматическим обновлением при всех операциях с сессией
- 🔄 **Steam Refresh Token Support**: автоматическое использование refresh токенов для предотвращения создания новых устройств при каждом входе

### 🌐 **Управление прокси и сетью**
- **🌐 Проверить прокси всех аккаунтов**: комплексная проверка всех прокси из конфигурации с детальным отчетом
- **📊 Детальная статистика прокси**: отображение назначенного IP:Port, полученного IP и статуса работы для каждого аккаунта
- **📈 Общая статистика**: количество работающих и проблемных прокси
- **🔍 Автоматическая диагностика**: выявление проблем с прокси и рекомендации по их устранению

## 🚀 Быстрый старт

### 1️⃣ **Установка UV**

UV - современный и быстрый пакетный менеджер для Python:

```bash
# Установка UV (если не знаете, то рекомендую ознакомится подробнее: https://docs.astral.sh/uv/)
curl -LsSf https://astral.sh/uv/install.sh | sh  # Linux/macOS
# или
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"  # Windows
```

⚠️ **Важно**: После установки UV **обязательно перезапустите терминал**, чтобы переменные окружения обновились и команда `uv` стала доступна.

### 2️⃣ **Клонирование и установка**

```bash
git clone https://github.com/dr11m/pySDA
cd pySDA
uv sync --python 3.10.8
```

💡 **Проверка установки**: Если команда `uv` не найдена, убедитесь что вы перезапустили терминал после установки UV.

### 3️⃣ **Настройка конфигурации**

Скопируйте файл `config.example.yaml` и переименуйте в `config.yaml`:

```bash
cp config.example.yaml config.yaml
```

Затем заполните ваши данные в `config.yaml`:

```yaml
# Отладочные настройки
debug_console_output: true  # Дополнительный вывод DEBUG/INFO/WARNING в консоль

# Минимальная задержка между запросами (в миллисекундах)
min_request_delay_ms: 1000

# Настройки аккаунтов
accounts:
  default:
    username: "ваш_steam_логин"
    password: "ваш_пароль"
    mafile_path: "accounts_info/ваш_логин.maFile"
    steam_id: "ваш_steam_id_64"
    api_key: ""  # можете оставить пустым (более не использется для работы)
```

### 4️⃣ **Добавление .maFile**

**Ручное добавление:**
1. Поместите ваш `.maFile` в папку `accounts_info/`
2. Переименуйте в формат `имя_аккаунта.maFile` (должно совпадать с именем в конфиге)

**Важно**: Имя файла `.maFile` должно точно совпадать с именем аккаунта в конфигурации. Например, если в конфиге указан аккаунт `my_account_1`, то файл должен называться `my_account_1.maFile`.

Начиная с текущей версии валидность `mafile_path` проверяется сразу при выборе аккаунта (fail-fast). Если путь неверный или файл отсутствует, контекст аккаунта не инициализируется, а в CLI выводится короткая ошибка.

### 5️⃣ **Запуск**

```bash
# Бот (автоматизация)
uv run python cli.py

# Browser Launcher (ручной вход в Steam через браузер, опционально)
uv run python cli_browser.py
```

Для Browser Launcher сначала установите браузер Playwright:

```bash
uv run playwright install chromium
```

> **💡 Примечание о эмодзи**: Приложение использует эмодзи в интерфейсе для лучшего восприятия. Если на вашей системе эмодзи отображаются как квадратики или символы, рекомендуется:
> - **Windows**: Использовать Windows Terminal или PowerShell 7+
> - **macOS/Linux**: Обычно поддерживаются из коробки
> - **Серверы**: Эмодзи автоматически отключаются на серверах без поддержки Unicode

> **🔍 Отладка**: Если что-то не работает, подробные логи находятся в папке `logs/`.
> - `logs/log.log` — обычные логи приложения
> - `logs/error.log` — только ошибки с traceback
> - traceback для перехваченных исключений теперь всегда печатается в консоль (`stderr`) и сохраняется в `logs/error.log`
> - используется режим `stack only` (`diagnose=False`) без дампа локальных переменных
> - `debug_console_output: true` включает только дополнительный вывод DEBUG/INFO/WARNING в консоль

## 🤖 Автоматизация - главная фича

> **Это основная причина создания бота** - автоматическая обработка трейдов без вашего участия. Бот принимает трейды в веб-интерфейсе Steam, а затем автоматически подтверждает их через Steam Guard.

### 🏠 **Главное меню**

При запуске приложения вы увидите главное меню с 4 основными пунктами:

1. **👤 Действия с аккаунтом** - все функции для работы с выбранным аккаунтом
2. **🤖 Автоматизация** - настройка и запуск автоматической обработки трейдов
3. **🌐 Проверить прокси всех аккаунтов** - комплексная проверка всех прокси из конфигурации
4. **🚪 Выход** - завершение работы приложения

### ⚙️ **Настройки автоматизации**

При выборе `🤖 Автоматизация` → `⚙️ Настройки автоматизации` вы можете настроить:

**🕐 Временные интервалы:**
- Интервал проверки трейдов (рекомендуется 30-300 секунд, допустимо 10–3600)

**🎁 Автоматическое принятие:**
- Принимать подарки в веб-интерфейсе (когда вам дают предметы бесплатно)

**🔑 Автоподтверждение:**
- Подтверждать через Steam Guard трейды, уже принятые в веб-интерфейсе или отправленные трейды
- Подтверждать маркет-операции


**📊 Статистика и логи:**
- Ведение подробных логов всех операций
- Счетчики принятых/подтвержденных трейдов
- **Новое**: Улучшенное логирование с `print_and_log` утилитой

### ▶️ **Запуск автоматизации**

После настройки выберите `▶️ Включить авто принятие`:

**Что происходит в автоматическом режиме:**
1. **Проверка сессии** - каждые N секунд проверяется валидность cookies
2. **Поиск новых трейдов** - регулярная проверка активных трейдов
3. **Анализ трейдов** - определение типа (подарок/обмен/отдача)
4. **Принятие в веб-интерфейсе** - автоматическое принятие подарков
5. **Подтверждение через Steam Guard** - автоматическое подтверждение уже принятых трейдов (принятых или отправленных вами)
6. **Логирование** - запись всех действий в файлы логов

**Типы автоматически обрабатываемых трейдов:**
- 🎁 **Подарки** - трейды где вы получаете предметы бесплатно, а ничего не отдаете (принимаются в веб-интерфейсе)
- 🔑 **Ожидающие подтверждения** - автоматическое подтверждение через Steam Guard уже принятых трейдов

**Новые возможности:**
- ℹ️ **Информативные сообщения** - показывается когда нет трейдов для обработки
- 📝 **Улучшенное логирование** - все действия записываются в файл и выводятся в консоль
- 🔧 **Множественные аккаунты** - несколько аккаунтов обрабатываются последовательно (без параллельности)

**Безопасность:**
- Бот НЕ принимает трейды где вы что-то отдаете
- Все действия логируются для контроля
- Возможность остановки в любой момент

### 📊 **Мониторинг работы**

Во время работы автоматизации вы увидите:
- Статус текущих операций
- Количество обработанных трейдов
- Время последней проверки
- Ошибки и предупреждения
- Возможность остановки процесса

## 🌐 Browser Launcher — ручной вход в Steam через браузер

Отдельный CLI: изолированный браузерный профиль на каждый аккаунт, автозаливка cookies из хранилища, выбор прокси и расширений, защита от повторного запуска. Runtime бота не затрагивается.

### 🚀 Запуск

```bash
uv run python cli_browser.py
uv run steam-browser          # alias
uv run python -m browser_launcher
```

Перед первым запуском установите браузер Playwright: `uv run playwright install chromium`

### 📋 Меню аккаунтов

- `[*]` — браузер открыт (повторный запуск заблокирован), `[ ]` — доступен
- В строке аккаунта: имя, описание, `user`, `proxy ip` (без логина/пароля)
- После закрытия окна браузера управление возвращается в меню

### 🌍 Выбор прокси

1. Steam через прокси аккаунта, cs.deals напрямую
2. Прокси аккаунта для всего трафика
3. Без прокси (direct)
4. Свой прокси: `host:port`, `host:port:username:password`, `http://username:password@host:port`

### 🧩 Выбор расширения

- Расширения берутся из папки `browser_extensions/`
- Поддерживаются только распакованные: подпапка с `manifest.json` внутри
- `.crx` не поддерживается — распакуйте вручную в `browser_extensions/<имя>/`
- Если распакованных нет, шаг пропускается; выбранное расширение подключается при каждом запуске

### 🔐 Сессии и профили

- Профили: `browser_profiles/<account_name>/` (локально, вне git)
- Cookies читаются из storage (JSON/SQL) read-only и заливаются по доменам
- Повторная заливка: первый запуск профиля или флаг `--refresh-cookies`
- Маркер `.session_verified` — в профиле рабочая Steam-сессия

### ⚙️ Флаги

| Флаг | Описание |
|------|----------|
| `--config` | Путь к `config.yaml` (default: `config.yaml`) |
| `--url` | Стартовый URL; при явном флаге проверка Steam-сессии отключается |
| `--profile-root` | Каталог профилей (default: `./browser_profiles`) |
| `--refresh-cookies` | Принудительно перезалить cookies из storage |

> ⚠️ Нужна машина с GUI. Рекомендуемый сценарий: бот на сервере, браузер для ручного входа — на локальном ПК.
